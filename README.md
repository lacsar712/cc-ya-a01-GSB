# 风机偏航对中台

现场技师**先在「机舱方位钉死台」钉死机舱方位，再报送偏航误差入队**；后台 worker 用数据库行锁认领待处理记录，按 ±1.5° 阈值写入「合格」或「偏航超差」。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 钉死台账规则

- 顶栏进入「机舱方位钉死台」：左区待钉机组（录入机组与方位角后执行钉死）、中区已钉档案（可改数）、右区退回说明。方位角**不挂总览尾列**，通过单据详情查看。
- **未钉先报，整单退回**：机组未在钉死台账钉死方位时，报送请求直接 400 退回，队列不落任何记录，提示「方位未钉」。
- **同事务抄录**：查钉、抄方位、入队在同一数据库事务内完成，任何半笔写入都不会落库；单据内方位是入队当刻的快照。
- **改钉不溯及旧单**：钉死后在台账改数只影响之后的新单据，已办结单据的方位与结论不变。
- **并发只落一笔**：两名技师同时钉同一机组时，数据库主键保证只落一笔，另一笔当场 409 拒收。
- **权限**：技师（writer）可钉死、改钉、报送；观察员（reader）可翻阅钉死表与单据方位，不可钉、不可改、不可报。

## 验收

1. 以 technician 登录，进入「机舱方位钉死台」：为 **W01（一号机）钉方位 0.2°**（左区录入 → 执行钉死，中区出现档案）。
2. 回总览报送 **W01 偏航 0.8°**：单据进「待处理」，单据方位为 0.2°；worker 办结后结论「合格」，再查单据方位仍为 **0.2°**。
3. **W07（七号机）未钉直接报送**：被整单退回，提示方位未钉，列表不出现该单。
4. 在钉死台把 W01 改钉为 20.0°：旧办结单方位仍是 0.2°、结论不变；再报一单，新单方位为 20.0°。
5. 两名技师并发钉同一机组：只一笔落库，另一笔收到 409 拒收提示。
6. observer 登录：可翻钉死表与单据方位，页面无钉死/改钉/报送入口，直接调接口返回 403。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/turbines` | 登录 | 机组名册及钉死档案（钉死台三区数据源） |
| POST | `/api/azimuth-pins` | 技师 | 钉死方位；重复/并发钉死返回 409 |
| PUT | `/api/azimuth-pins/{code}` | 技师 | 改钉台账现值，不影响旧单 |
| GET | `/api/logs` | 登录 | 单据列表（含入队当刻方位快照） |
| POST | `/api/logs` | 技师 | 查钉+抄方位+入队同一事务；未钉 400 整单退回 |

## 技术栈

- 后端：Quart、psycopg、`worker.py`（`FOR UPDATE SKIP LOCKED`）、Hypercorn
- 前端：Lit、TypeScript、Vite；生产镜像内 nginx 反代 `/api`
- 镜像源：DaoCloud 基础镜像、清华 PyPI、npmmirror npm
